# Official data map

Everything below was read out of the synced bundles; it describes **where** facts
live, not the facts themselves. Row counts come from the current sync and are a
sanity check, not a contract - re-run `python scripts/d2r_query.py status` after
every `west update`.

## 1. `upstream/website/static/data/`

Generated by `d2r-multi-export-tool` from the mod's `data/global/excel/*.txt`.
Precedence for every input table: the mod's copy, else the CASC copy, else the
exporter's bundled reference (`extras/source-report.txt` lists all 46 inputs and
which root each came from).

`manifest.json` (schema 2) is the integrity contract: `Succeeded`, `Complete`,
`Steps[]` (`{Producer, Status, Outputs, NotWritten?, Removed?, Message?}`) and
`Files[]` (`{Path, Bytes, Sha256, Producer}`). `Files[]` never lists the manifest
itself. Producers today: `skill-icons` 240, `item-presentation` 613, `keyed-core` 9,
`strings` 13, `extras/*` 5, one per calculator bundle.

### `keyed/*.json` - authoritative catalog data

bundle. None of these files is a dict keyed by name despite the folder name.

### `strings/<locale>.json` - authoritative localized text

Flat `key -> printf template`, 13 locales. `enUS` holds 6235 keys; every other
locale holds 6206, i.e. **29 keys exist only in enUS** (loot-filter labels such as
`Jewel Pliers`, `Keychain`, `Gem Bag` and the short codes `bpl`, `hpf`, `mpf` …).
Placeholder census over enUS: `%d` 398, `%+d` 272, `%%` 262 occurrences across 250
keys, `%s` 76, one indexed pair (`%0`/`%1`) used for Slavic word order.

`upstream/website/src/lib/data/cube-recipe-aliases.json` maps 2012 historical
`cubemain` row numbers onto current `cr-...` ids (`basis: 2edc09fe4ab877d1`) so
saved build links survive id rotation.

### `extras/*.txt` - the exporter's own diagnosis

Read these before claiming anything is missing. `import-report.txt` (0 errors,
2 warnings: 11 `skills.txt` rows and 655 `monstats.txt` rows whose informational
`*Id`/`*hcIdx` disagree with the engine index), `casc-fallback-report.txt` (11 keys
promoted from CASC because the mod does not ship them), `missing-translations.txt`
(0), `asset-report.txt` (1314 named variants drawn with base artwork, each with the
requested mapping and failure reason), `source-report.txt` (46 inputs, 44 mod + 2
CASC, 0 not found).

## 2. `upstream/wiki-content/`

WikiJS export. 36 `.md` + 90 `.html` pages; **84 html pages have no `.md` twin** and
30 `.md` have no `.html` twin, so index both forms. `.md` carries YAML frontmatter
between `---` lines; `.html` carries the same keys in a leading `<!-- ... -->`
comment (`title`, `description`, `published`, `date`, `tags`, `editor`,
`dateCreated`).

## 3. `upstream/export-tool/docs/`

The contract layer. `WEBSITE-INTEGRATION.md` (skill data contract, item levels,
roll preservation, name/asset rules, cube identity, engine row identifiers,
manifest semantics), `SKILL-CALCULATIONS.md` (line members, axes, BBE grammar,
documented evaluator limits), `DROP-CALCULATOR.md`, `HEALTH-CALCULATOR.md`,
`IAS-CALCULATOR.md`, `LOOT-FILTER.md`, `PROPERTY-RANGES.md`, `TESTING.md`.
Website-side docs worth reading before answering design questions:
`upstream/website/docs/{SKILL-PLANNER,DROP-CALCULATOR,LOOT-FILTER,builds}.md` and
`upstream/website/AGENTS.MD`, which states that `static/data/keyed/**` is the
authoritative catalog and `static/data/strings/**` the authoritative localization.
